    ▶ Configurações da transcrição
    A velocidade depende do modelo e de quantos processadores a VPS tem. Na primeira vez com cada modelo, o servidor baixa o modelo (alguns minutos). Depois fica salvo. Para o mais rápido de todos, use a OpenAI.
    Crie em platform.openai.com/api-keys. Fica salva só no servidor.
    Deixe desmarcado para transcrever o áudio inteiro, inclusive músicas. Marque só para palestras e reuniões com muitas pausas: fica mais rápido, mas pode pular canto e falas com música de fundo.

    Achar canais de música com IA em alta

    Canais novos de música feita com IA (Suno, Udio…), com vídeos recentes e muitas visualizações, em qualquer lugar do mundo. Dados oficiais da API do YouTube.

    Busca vídeos que mencionam IA/Suno/Udio e confirma por três sinais: selo oficial de conteúdo sintético declarado pelo criador, menções no título/descrição/tags e na descrição do canal. Canais de IA que não declaram nada em lugar nenhum não têm como ser identificados.
     
    ▶ Configurações da busca (chave da API do YouTube)
    Cota gratuita: — unidades usadas hoje (renova todo dia por volta das 5h). Cada busca de região/gênero usa 100.
    1. Acesse console.cloud.google.com e entre com sua conta Google.
    2. No topo, crie um projeto (ex.: YTB Conversor).
    3. Menu ☰ → APIs e serviços → Biblioteca → procure YouTube Data API v3 → Ativar.
    4. APIs e serviços → Credenciais → Criar credenciais → Chave de API. Copie a chave (começa com AIza).
    5. Recomendado: clique na chave → Restrições de API → restringir à YouTube Data API v3 (não restrinja por site/IP).
    6. Cole a chave acima e clique em Salvar. Pronto: é gratuito, sem cartão.
